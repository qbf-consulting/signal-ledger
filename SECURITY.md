# Security Policy

## Reporting

Please report security concerns privately to QBF Consulting rather than opening a public issue while the repository remains under active development.

Contact: ask@qbfconsulting.digital

## Scope

Security reports may include:

- unsafe source ingestion behavior;
- provenance or evidence-integrity failures;
- path traversal or storage corruption;
- dependency vulnerabilities;
- mechanisms that can misrepresent derived data as authoritative evidence.

Do not include sensitive third-party data in reports.
