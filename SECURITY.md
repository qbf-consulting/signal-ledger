# Security Policy

## Reporting

Please report suspected security vulnerabilities privately to QBF Consulting LLP. Do not open a public issue for a vulnerability until coordinated disclosure is agreed.

Contact: ask@qbfconsulting.digital

When possible, include the affected version or commit, reproduction steps, expected and observed behavior, and the security or evidence-integrity impact. Do not include secrets, credentials, personal data, or sensitive third-party material in reports.

## Scope

Security reports may include:

- unsafe source ingestion behavior;
- provenance or evidence-integrity failures;
- path traversal or storage corruption;
- dependency or workflow vulnerabilities;
- mechanisms that can misrepresent derived data as authoritative evidence;
- accidental exposure of credentials or sensitive source material.

## Disclosure

QBF Consulting LLP will assess reports against the implemented Signal Ledger capability. Publication or disclosure should preserve evidence needed to reproduce the issue while avoiding unnecessary exposure of sensitive material.
