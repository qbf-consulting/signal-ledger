# Significance and change

Signal Ledger does not compute a universal importance score. Significance is a profile-driven judgment expressed as independent dimensions.

Every dimension assessment requires a level, justification, and evidence references. Coverage volume is deliberately absent from the assessment model: five reports can corroborate an event but do not make it materially significant.

Change detection compares the current assessment with a prior assessment and emits the dimensions whose levels changed. This supports the product question: **what changed since I last looked?**

Profiles may select or constrain dimensions, but they must not mutate the underlying observation/event evidence.
